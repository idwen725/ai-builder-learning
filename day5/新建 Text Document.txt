理解：
- Python 可以通过 HTTP 与远程服务器通信
- API 是软件向其他软件提供的接口
- Request 是客户端请求，Response 是服务器响应
- JSON 常用于 API 数据交换
- requests.get() 可以发送 GET 请求
- response.json() 将 JSON 响应解析成 Python 数据
- try/except 处理异常后程序仍可能继续执行
- try 的 else 只在 try 正常完成时执行
- API 调用成功返回 data，失败可以返回 None
